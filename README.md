Registro de visitas al aula MakerSpace

Este programa permite registrar y consultar las visitas de estudiantes al aula MakerSpace.

Se registran tres datos: nombre, curso y motivo de visita.

Se utilizan objetos, arrays, funciones, funciones flecha, métodos de arrays y estructuras condicionales.

Los datos se guardan en una base de datos SQLite.
